# Repository identity records

Các seal, source/data/environment identity và historical dirty-worktree patch
được giữ ở đây để audit provenance. Chúng không phải runtime input của pipeline
và không được đặt trong `data/` hoặc `artifacts/`.

Lưu ý: evidence/submission packet có thể vẫn dùng thư mục nội bộ `identity/`;
đó là packet contract độc lập với layout repository này.
