# interface — Điểm vào

| Thư mục | Nội dung |
|---|---|
| `cli/` | Điểm vào chính, khớp các target trong `Makefile` |
| `api/` | REST cho Web Chatbot demo — **phụ trợ, không thuộc phần chấm điểm** |

**Bất biến:** CLI (sinh bài nộp) và API (demo) là **hai adapter trên cùng một facade**.
Không được có đường đi thứ hai. Xem `docs/ARCHITECTURE.md §10`.
